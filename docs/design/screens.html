모바일 색

모바일과 PC 는 따로 저장돼요. 고친 칸은 파랗게 보이고, ◎ 를 누르면 그 파트가 화면에서 잠깐 분홍으로 깜빡여요.

여기서 바꾼 색은 이 브라우저에만 저장돼요. 실제 웹에 넣으려면 위 「색 값 복사」 내용을 전해 주세요 (web/src/lib/theme.ts 에 옮김).
지도 그림(길·물·동네 이름) 색은 팔레트 쪽이라 여기서는 안 바뀌어요.

웹 서버가 꺼져 있어서 화면을 못 불러와요. web 폴더에서 npm run dev -- -p 3100 으로 켠 뒤 「새로 고침」을 눌러 주세요. (Claude 에게 「웹 서버 켜 줘」라고 해도 돼요)
