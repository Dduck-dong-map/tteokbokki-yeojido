### 2-2. 지도 — 지적이 맞다

- 우리 웹 지도(MapLibre + OpenFreeMap, `web/src/components/map/dongyeoStyle.ts`)는 확대해도 **동 · 구 · 역 · 물 이름만** 나온다. **길 이름 · 건물 이름 · 주변 상호가 없어서** 가게 위치를 짚기 어렵다.
- 팀 PRD · 기술스택은 이미 지도 기본을 **네이버 지도 JS v3 + 커스텀 스타일**로 잡고 있다(`MapView` 뒤에 두고 MapLibre 는 대체). PRD 92줄에 「확대하면 네이버 실제 지도로 넘어가는 화면(화면 시안 v2 제안) — 사용자 확인 전」이 적혀 있다.
- 네이버 지도는 **네이버 클라우드 콘솔에서 Maps 신청 · 키 발급**이 필요하다(로드맵 2단계 선행 조건). 계정 일이라 사용자나 팀원이 한다.
