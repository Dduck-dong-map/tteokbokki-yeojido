# 떡볶여지도 MVP 개발 로드맵

떡·스타일·맵기 취향으로 실제 떡볶이 가게를 지도에서 골라 길찾기까지 가게 하고, 가입 없이 누구나 올리고 고치는 「모두가 고치는 지도」를 청년부(3청) 1차 사용자에게 Vercel + Supabase 로 내놓는다. 기능 정의와 수용 기준은 [PRD](PRD.md), 배포 절차와 환경 변수는 [기술 스택](개발/기술스택_v1_2026-10-28.md) 문서에 있다. 1차 MVP 코드는 대부분 구현되어 있어 Phase 마다 끝난 일(`[x]`)과 남은 일(`[ ]`)이 함께 있다. 예상 소요 시간은 남은 일 기준 추정치이고, 단위는 한 사람과 AI 코딩 에이전트가 함께 일하는 작업일이다.

## 범위 밖

PRD 11절의 항목은 이 로드맵의 완료 조건이 아니다. MVP 이후로 둔 것은 「승인 후 공개」 스위치와 등록 검토함, 어드민 시안 화면의 실제 데이터 연결, 사진 1장 필수, 주소 · 상호 검색, 역에서 걷는 시간, 등록 단계 기록, 「같이 가요」 글의 가게 등록 잇기다. 이 가운데 이용약관 · 개인정보 처리방침, 사장님 · 권리 침해 요청 창구, 캡차 셋은 PRD 가 「공개 출시 전 필수」로 적어 Phase 5 에만 있다. 운영자 사전 승인 제보, 맵기 투표, 이용자 로그인 · 크루, 포인트 · 순위 · 쿠폰 · 광고, 떡지순례 도장 · 사장님 센터 · 배달 · 앱, 공공데이터 후보 적재는 이번에 하지 않는다.
