읽는 법

  • 회원 표가 없다. 「누가」는 device · ip(해시값) 두 칸으로만 가른다.
  • 가게(stores)를 지우면 붙은 기록 다섯 표의 줄이 함께 지워진다(CASCADE). 글(posts)만 남고 store_id 가 비워진다(SET NULL). 서비스에서는 가게를 지우지 않고 status 로 내린다.
  • place_lists.store_ids 는 가게 id 의 jsonb 배열이라 DB 가 관계를 지켜 주지 않는다(점선).
  • stores.location 은 트리거 stores_location 이 lat · lng 에서 채운다.
  • 모든 표의 RLS 가 켜져 있고 정책이 0개다. 표 주인(서버 연결)만 읽고 쓴다.
  • 지금 이 컴퓨터의 앱은 DATABASE_URL 이 없어 파일 저장소(.data/db.json)로 돈다. 이 그림은 DATABASE_URL 을 붙였을 때 앱이 쓰는 Postgres 의 모습이다.
