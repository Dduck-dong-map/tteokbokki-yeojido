# 떡볶여지도 팔레트 T — shadcn / tweakcn 변수 (2026-11-01)

슬랙 #design 10-28(irisonestar) 반영: 주 버튼은 옥빛, 빨강은 포인트(로고·맵기 도장·제보 버튼)만. 바탕은 한지 미색, 글은 먹색.
웹앱(`web/src/lib/theme.ts`)의 기본 팔레트 **T** 와 같은 값이다. 화면 설계 보드 `docs/공유/design/index.html?pal=T` 로 바로 볼 수 있다.

팀장이 만든 tweakcn 「떡볶이 초안 1」(https://tweakcn.com/themes/cmvruh8t4000004l371uk53sr)을 열어 **Custom → 아래 변수를 붙여 넣으면** 같은 느낌으로 비교할 수 있다.

## shadcn 변수 (라이트)

```css
:root {
  --background: #F3F0E9;
  --foreground: #1C1C1B;
  --card: #FDFCF9;
  --card-foreground: #1C1C1B;
  --popover: #FDFCF9;
  --popover-foreground: #1C1C1B;
  --primary: #2A6159;            /* 주 버튼 옥빛 */
  --primary-foreground: #FFFFFF;
  --secondary: #E9E5DC;          /* 보조 버튼·칩: 면과 먹을 섞은 톤 */
  --secondary-foreground: #1C1C1B;

  --destructive: #B42318;        /* 고추장 레드 = 포인트(제보 버튼)·경고 겸용 */

  --border: #D9D4C9;
```

- 맵기 1~5 단계색(`--chart-1~5`)은 팔레트와 상관없이 고정(기획안 v5 8절).
- 다크(N6 먹밤)는 아직 shadcn 변수로 옮기지 않았다. 필요하면 `theme.ts` 의 `derive()` 가 내는 값을 그대로 쓰면 된다.
