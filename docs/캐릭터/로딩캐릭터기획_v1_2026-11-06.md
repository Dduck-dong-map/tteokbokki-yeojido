## 어떻게 뜨나

| 상황 | 동작 |
| --- | --- |
| 첫 진입 · 폰 지도 홈 | 화면 전체. 로고 + 호랑이 + 「호호, 떡 식히는 중…」 |
| 첫 진입 · 768px 이상 | 지도 칸만. 목록과 가게 상세는 먼저 쓸 수 있다 |
| 폰에서 가게 주소로 바로 | 안 띄움(큰 지도를 안 켠다) |
| 서버 자료를 기다릴 때 | 같은 호랑이 (`(map)/layout.tsx` 의 `Suspense fallback`) |
| 다른 화면에 갔다 돌아올 때 | 안 띄움. 새로고침하면 처음부터 |

- 한지 바탕은 바로 깔아 덜 된 화면을 가리고, 호랑이는 0.3초 뒤에 나타난다. 나타났으면 0.6초는 보여 준다.
- 지도가 뜨거나, 실패하거나, 8초가 지나면 걷힌다. 8초까지 실제 지도 타일이 하나도 없으면 「지도를 불러오지 못했어요. 주소와 길찾기는 그대로 쓸 수 있어요.」 를 띄우고, 타일이 늦게라도 오면 내린다.
- 스크립트가 죽어도 9초 뒤에는 CSS 만으로 투명해지고 눌림도 통과한다.
- 움직임 줄이기를 켠 기기에는 멈춘 그림 + 글자만.
