## 2. 기획 팀장 피드백 전문 요지

1. **전체:** 기능·운영 구조가 세세해서 놀랐다. 맵기 도장·대동여지도 콘셉트는 동아리 개성이 잘 드러난다. **다음 주 완성이 목표라면 기능 확장보다 실제 사용 편의**에 집중.
2. **디자인·색:** 전통 지도 콘셉트와 맵기 도장은 **유지**. 지도를 실제로 쓸 때 가독성이 중요하니 **배경·장식은 복잡하지 않게**. 희망: **고추장 레드를 포인트 컬러**로 쓰되 **메뉴·가게 정보·버튼이 쉽게 구분**되게.
3. **도장 아이디어:** 숫자를 터치하면 **도장이 휙 돌아가며 그 맵기의 표정**이 나오면 재미있겠다. 단 **지도에서는 가게 상세 열기가 기본**, 이런 인터랙션은 **상세 화면에서**.
4. **메인 UI/UX:** 접속하자마자 **주변 떡볶이집**을 찾고 싶다. **검색 → 가게 선택 → 상세 → 길찾기** 흐름이 가장 직관적. 떡·스타일·맵기 필터는 좋지만 **처음부터 많은 선택을 요구하지 말고 원할 때만**. **필터 결과 0이면 초기화**할 수 있게. 가게 정보는 **이름 · 위치 · 떡볶이 종류 · 맵기 · 대표 가격 · 길찾기** 순으로 우선.
5. **제보:** 제보 완료 때 어묵 주는 것 좋다. **어묵은 어디에 쓰는 것인가?**(질문)
6. **범위:** 이번에 모든 기능을 완성하려 하지 말고 **맛집 탐색 · 길찾기 · 제보**를 불편 없이 쓰는 수준이 1차 목표. **캐릭터 확장 · 복잡한 자동화 · 운영 통계는 추후**.
7. (irisonestar 덧붙임) 1차 MVP는 금방 된다 했으니 **UI/UX 먼저 만들어 보고 괜찮으면 바로 배포 → 추가**. **어드민은 추후 확장**.
