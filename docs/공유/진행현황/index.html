D0 결정 ~11/1→M1 디자인 11/2~8→M2 데이터 ~11/22→M3 어드민 ~12/6→M4 가게 300곳→M5 베타 12/14→출시 1/11 주

  4. 제보 흐름에 「별점은 없고 태그만」
  5. M3 어드민 9개 할 일 + 관문 G4(하루 20분 운영)

팀이 원하는 것(10-28) + 지금 상태

D0 결정 ~11/1→M1 1차 UI/UX → 바로 배포 11/2~8→팀 피드백→M2 데이터(+평점 저장)→M3 어드민→M4 가게→베타 · 출시(다시 계산)
