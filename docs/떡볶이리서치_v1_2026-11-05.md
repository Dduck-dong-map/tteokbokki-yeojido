# 떡볶이 리서치 v1 (2026-11-05)

왜 했나: 호랑이 시안에서 떡 끝에 꼬치를 세로로 꽂아 그렸다. 사용자 11-05: 「떡볶이에 대해 리서치해서 학습해 누가 떡볶이를 세로로 꽂아 먹냐?」 앞으로 떡볶이가 나오는 그림·문구는 이 문서의 **그림 규칙**을 먼저 본다.

## 그림 규칙

| | 이렇게 | 이렇게 그리면 안 됨 |
| --- | --- | --- |
| **꽂는 방향** | 떡 **옆면 가운데**를 꼬치·이쑤시개가 직각으로 뚫는다(T자) | 떡 끝에 꽂아 막대사탕·핫바처럼 세우기 |
| **개수** | 한 개 = 떡볶이를 이쑤시개로 찍은 모습 | 여러 개를 나란히 꿰면 떡볶이가 아니라 **떡꼬치** |
| **떡 색** | 소스가 얇게 입혀져 떡 색이 비치는 밝은 주황빛 빨강, 윤기 | 짙은 빨강으로 전부 칠하기(소시지처럼 보인다) |
| **떡 모양** | 통통한 원기둥, 자른 끝은 살짝 둥글다. 길이가 굵기의 3~5배쯤(사진 눈대중) | 너무 길고 곧은 막대 |
| **같이 나오는 것** | 깨 · 파 · 어묵 · 삶은 달걀 | |
| **담는 그릇** | 종이컵 + 이쑤시개, 분식집 접시, 즉석 떡볶이 냄비 | |

## 알아낸 것

### 어떻게 먹나

- 학교 앞 **컵떡볶이는 이쑤시개로 떡 하나를 콕 찍어 먹는다.** 「컵떡볶이를 손에 쥐고 이쑤시개로 떡 하나를 콕 찍어 먹으면」([인사이트](https://www.insight.co.kr/news/235399)), 「종이컵에 담긴 떡볶이를 이쑤시개로 먹었습니다」([경인일보](https://www.kyeongin.com/article/1759161)).
- 종이컵에는 떡과 어묵을 함께 담았다([인사이트](https://www.insight.co.kr/news/235399)).
- 부산처럼 떡이 굵고 긴 집은 「가위로 자르거나 깨물어서 소스에 찍어 먹도록 한다」([일간스포츠, 2009](https://isplus.com/article/view/isp200903250008)).
- 튀김·순대를 소스에 찍어 먹기도 하고, 분식집에서는 순대·튀김·어묵 국물과 함께 낸다([Taste Korean Food](https://www.tastekoreanfood.com/ktrend/from-royal-court-to-street-food-korean-tteokbokki)).

### 꽂는 방향의 근거

- **떡꼬치도 떡을 가로로 꽂는다.** 레시피에 「나무 꼬치 하나당 5개 정도씩 나란히 가로로」 꽂으라고 나온다(검색 요약으로 확인, 원문 페이지는 403으로 못 열어 어느 글인지 특정하지 못함).
- 소떡소떡 사진(스톡, 비AI 표시)을 직접 보니 떡이 꼬치와 **직각**으로 꿰어져 있다.
- **시안 「나」도 떡이 꼬치와 직각이었다.** 사용자는 떡 개수만 하나로 줄이라고 했는데, 내가 프롬프트에 「꼬치와 나란히 세우고 아래쪽 끝만 꿴다」고 써서 방향까지 틀어졌다.
- 한계: 이쑤시개가 떡볶이 떡에 들어가는 각도를 글로 직접 적은 자료는 찾지 못했다. 「콕 찍어」라는 표현, 떡꼬치·소떡소떡의 꿰는 방식, 사용자의 말로 판단했다.

### 떡

- 재료로 나누면 쌀떡 · 밀가루를 10~20% 섞은 혼합떡 · 밀가루떡 세 가지([일간스포츠, 2009](https://isplus.com/article/view/isp200903250008)).
- 크기: 보통 지름 1cm 미만 · 길이 5cm 정도. 부산은 가래떡 굵기 · 길이 10~15cm(같은 기사, 2009년이라 지금과 다를 수 있음).
- 실제 사진(스톡, 비AI 표시 2장)에서 본 것: 떡은 밝은 주황빛이고 소스 사이로 떡 색이 비치며, 끝은 둥글게 무너져 있다. 깨 · 파 · 삶은 달걀 · 어묵이 함께 보인다.

### 역사

- **궁중 떡볶이:** 간장 · 참기름으로 볶아 맵지 않다. 가장 이른 기록으로 19세기 말 조리서 『시의전서』가 꼽힌다([Taste Korean Food](https://www.tastekoreanfood.com/ktrend/from-royal-court-to-street-food-korean-tteokbokki)).
- **고추장 떡볶이:** 1953년 서울 신당동 노점의 마복림(1921~2011)이 시초라는 설이 가장 유력하다. 고추장에 춘장을 섞었고, 짜장 소스 묻은 떡을 맛본 일에서 비롯됐다는 이야기가 전한다. 확정된 사실이 아니라 **설**로 쓴다.
- **먹는 곳·변형:** 분식집 · 포장마차 · 즉석 떡볶이(식탁에서 끓임) · 라볶이.

## 자료의 한계

- 블로그·요약 글이 많아 수치와 연도는 참고용이다. 서비스 문구에 역사를 쓰려면 다시 확인해야 한다.
- [Ocado 레시피](https://www.ocado.com/recipes/street-style-tteokbokki/4IrRWRDU3kb35q2ejs5OBz)(노점에서 이쑤시개만 받았다는 회고)와 [레딧 글](https://lr.in.psf.lt/r/KoreanFood/comments/11fs92k/sotteok_sotteok)은 검색 요약으로만 봤고 원문은 열리지 않아 위 근거에 넣지 않았다.
- 스톡 검색의 「꼬치·포크에 꽂은 떡볶이」 사진은 AI 그림 표시라 근거로 쓰지 않았다.
