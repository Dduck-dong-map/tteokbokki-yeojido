# StoreListItem

목록의 가게 한 칸. 칸 전체가 가게 상세로 가는 링크 하나다(안에 다른 버튼을 넣지 않는다).

- 가게 이름은 조선100년체 `heading-4`(20px), 두 줄까지 보이고 나머지는 말줄임. 주소·거리는 `body-medium` `text-secondary`.
- 순위가 있으면 앞에 순위 숫자(`text-brand`), 스크린 리더는 「순위 1」로 읽는다.
- 칸 사이는 `border-default` 선, 최소 높이 72px.
- 지도의 핀을 키보드로 다 돌 수 없으니 **이 목록이 지도의 대체 경로**다. 지도에 보이는 가게는 모두 목록에도 있어야 한다.
- 쓰는 쪽이 줄 것: `name`, `meta`, `href`, 필요하면 `tags`·`spicy`·`rank`.
