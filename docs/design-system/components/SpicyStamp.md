# SpicyStamp

맵기 1~5 단계는 앱에서 세 가지로 보인다 (11-13 수정판에서 앱에 맞춰 고침 — 예전 문서의 「색 원 + 숫자」는 쓰지 않는다).

- **고추 개수 알약** — 지도 핀과 목록 줄. 고추 그림 N개 + `spicy-N` 바탕. 지도와 목록이 같은 모양이라 화면 사이가 이어진다.
- **게이지 도장** — 목록 줄·상세. 도장이 아래에서부터 N/5 만큼 차오른다(`SpiceStamp`). 안 찬 부분은 `--stampbg`.
- **도장이 얼굴** — 목록 카드·상세 앞면은 맵기 1~5 표정(`public/brand/dojang_1~5.svg`), 누르면 뒷면 게이지 도장(`FlipStamp`).
- 상세에는 「맵기 N · 기준 설명」 글이 함께 있어, 색을 못 구분해도 단계를 읽는다. 스크린 리더는 「맵기 N단계 ○○맛」으로 읽는다.
- 단계 이름: 1 순한맛 · 2 조금 매운맛 · 3 보통 매운맛 · 4 매운맛 · 5 아주 매운맛.
- 맵기 빨강은 오류 빨강(`text-error`)과 섞지 않는다.
- 🔴 팀이 정할 것 (게슈탈트 「단순성」): 한 가게에서 맵기를 2~3가지로 보인다. 「고추 개수」를 모든 화면의 주인공으로 두고 게이지·얼굴은 상세에서만 크게 쓰면 더 단순하게 읽힌다.
