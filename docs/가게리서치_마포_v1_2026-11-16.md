- **경성떡볶이**: 2026-05-09 방문 기록이 있으나 다이닝코드 목록 한 곳엔 「영업 종료」 → 확인 필요(맵기도 빈 칸이라 아직 안 넣음).
- **마포원조떡볶이 떡 종류**: 2026-07 후기 밀떡 · 2026-01 후기 쌀떡 → 최근 쪽(밀떡).

- 다이닝코드 가게 페이지 · 네이버 블로그는 이번 환경에서 안 열려서 검색 요약으로만 본 내용은 원본 json basis 에 「(검색 요약)」.
