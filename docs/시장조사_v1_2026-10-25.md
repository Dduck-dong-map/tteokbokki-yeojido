# 시장조사: 떡볶여지도 SWOT 분석

2026-10-28 다시 씀 (2026-10-25 조사 자료 기반) · 서비스 20곳 상세 비교표는 온라인 원본(https://claude.ai/artifact/64kZZtqct2fqTKxkjHbVQX 「시장조사」 탭)과 이 파일의 이전 깃 기록에 있다.

**결론:** 떡 종류·맵기로 거르고 익명 제보로 채우는 떡볶이 지도는 국내외에 없다. 빈 자리는 확실하지만, 이긴 쪽(HappyCow, 두쫀쿠맵)과 진 쪽(망고플레이트, Corner)을 가른 것은 기능이 아니라 **처음 열었을 때 핀이 차 있는가**와 **정보가 계속 새로 고쳐지는가**였다.

## SWOT

| | 도움이 되는 것 | 해가 되는 것 |
| --- | --- | --- |
| **내부** | **강점 (S)**<br>1. 빈 칸 선점: 떡 종류·맵기 필터 + 사용자 제보 떡볶이 지도는 없다. 기존 떡볶이 지도는 모두 운영자가 고른 목록이다<br>2. 맵기 표준: 누구나 아는 신라면을 3단계 기준점으로 삼는다<br>3. 가볍게 시작: 가입 없는 모바일 웹, 1인 운영, 공개 출시 후 월 약 6만 원대 | **약점 (W)**<br>1. 데이터 0곳에서 출발: 출시 전 300곳을 직접 채워야 한다<br>2. 1인 운영: 제보 승인·검수가 병목이다<br>3. 근거가 얕다: 취향 설문은 표본이 작고 결과가 서로 엇갈리며, 실제 사용자 인터뷰가 아직 없다<br>4. 이름·도메인·상표·손글씨 사용권이 정해지지 않았다 |
| **외부** | **기회 (O)**<br>1. 대형 지도(네이버·카카오)는 유행 목록만 만들고 떡·맵기 같은 속성 필터는 없다<br>2. 동네 커뮤니티 확산 경로가 검증됐다(거지맵 → 당근)<br>3. 관심층이 크다: 인스타 #떡볶이 325만 건, 배민 떡볶이 마스터즈 예선 57.8만 명, 대구 떡볶이 페스티벌 33만 명<br>4. 고정 태그가 쌓이면 데이터 자체를 팔 수 있다(라멘 데이터베이스, 식신) | **위협 (T)**<br>1. 대형 지도는 유행 목록을 몇 주 만에 만든다(흑백요리사2 목록 조회 약 60만)<br>2. 제보형 지도의 고질병: 사라진 가게가 남고, 계절에 따라 이용이 준다(가슴속 3천원 여름 급감)<br>3. 유행 맛이 빨리 바뀐다(마라로제 주문 반년 새 6.3배, 배떡 매장 감소)<br>4. 수익화가 신뢰를 깎는다(거지맵 전면 광고 불만, 망고플레이트 종료)<br>5. 지도 API 무료 한도·요금 정책이 바뀐다 |

## 전략

| 조합 | 할 일 |
| --- | --- |
| **S×O 공격** | 신라면=3 기준표와 떡·스타일 필터로 "떡볶이 취향 표준"을 먼저 만든다. 마포·서대문 대학가 커뮤니티에서 시작하고, 쌓인 태그는 연 1회 "지역 떡볶이 100곳" 같은 발표로 화제를 만든다 |
| **W×O 보완** | 공공데이터 인허가 후보 + 크루 확인으로 300곳을 채우고, 첫 지역을 좁혀 핀 밀도를 지킨다. 개발 전에 떡덕 5명을 관찰해 필터 보기를 검증한다 |
| **S×T 방어** | 유행 목록이 아니라 속성 필터로 차별화한다. 유행 맛은 태그 하나만 더하면 되도록 고정 태그 목록을 운영자가 관리한다 |
| **W×T 회피** | '아직 있어요'와 마지막 확인일로 최신성을 지킨다. 노출 순서를 팔지 않고 전면 광고를 쓰지 않는다. 내 기록 내려받기를 처음부터 두고, 지도는 교체 가능한 구조로 만든다 |
