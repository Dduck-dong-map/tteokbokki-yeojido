| 지도 스타일 | 화면/Style.dc.html | 대동여지도 → 떡볶여지도 지도 대응표, 도장 범례, 지도 색 |

## 그림

- `그림/map_mapo.svg`: 마포·서대문 일부 지도 바탕(그림용, 실제 축척 아님). `만든_스크립트/gen_map.py` 로 다시 만든다.
- `그림/logo_red.png`, `sign_red.png`, `slogan_ink.png`: 컨셉 이미지에서 오린 로고·서명·슬로건(투명 배경). `만든_스크립트/cut_logo.py`.
- `그림/ref_zoom_*.jpg`: 참고 이미지(../참고_대동여지도.jpg) 확대 조각.

가게 이름·가격·거리·제보 수는 화면 설명용 예시다.
