## 1. 참고 그림에서 가져올 것 / 안 가져올 것

| 가져올 것 | 어떻게 옮기나 |
| --- | --- |
| 한반도 = 호랑이 몸 (머리 동북, 앞발 서해, 꼬리 북쪽) | 그대로. 시안 v1 3a 가 이미 이 구도 |
| 치켜든 머리 · 벌린 입 · 치켜뜬 눈 | 입에 **떡 한 가닥**(또는 떡꼬치)을 물려 떡볶이 지도임을 말함 |
| 주황 털 + 먹 줄무늬 | 털은 한지 위에서 고추장 빨강과 구분되게 노랑 쪽 주황, 줄무늬는 팔레트 글자색(먹) |
| 청록 바다 + 점 뿌림 | 팔레트 「물」 색(T 기준 #A3C7BC) · 점은 한지 섬유 결로 |
| 왼쪽 위 세로 글씨 | 그 자리에 붓글씨 로고 |

안 가져올 것: 그림을 그대로 베끼기(구도·분위기만) · 사실적 털 묘사(캐릭터 1·2 와 한 세계가 되게 선 단순화) · 세로 글씨 한자.

## 2. 방향 세 가지

| | 가) 맹호 지도 | 나) 떡 문 호랑이 | 다) 호랑이 도장 |
| --- | --- | --- | --- |
| 무엇 | 한반도 전체가 호랑이, 채색 민화 | 호랑이 머리만 크게, 떡꼬치 물고 윙크 | 빨간 인주 한 색 호랑이 얼굴 도장 |
| 쓰는 곳 | 스플래시(첫 1~2초) · 지도 불러올 때 | 제보 완료 · 결과 0곳 · 위치 허용 묻기 · 화면 전환 | 앱 아이콘 후보 · 공유 이미지 워터마크 · 빙글 도는 로딩 표시 |
| 움직임 | 먹선 윤곽 → 색이 제주에서 백두로 **차오름**(게이지 도장과 같은 말) | 표정·말풍선만 바뀜(「찾았다!」 「여긴 아직 없네…」) | 빙글 돌다 「꾹」 찍힘 |
| + | 한 장으로 「한국 떡볶이 지도」 설명 끝 · 시안 v1 3a/3b 와 이어짐 | 작은 칸에도 또렷 · 재사용 쉬움 | 가장 싸고 작아도 또렷 · 「빨강은 로고·도장·제보 버튼에만」 규칙과 맞음 |
| − | 세로 긴 그림이라 가로 배너 불가 · 작은 화면에서 뭉개짐 | 귀여울수록 기상이 줄어듦 — 어디까지 귀엽게 할지 정해야 | 작으면 호랑이로 안 읽힐 수 있음(귀·수염·이마 王 으로 보완) |

추천 조합: **가 + 다** (스플래시는 가, 로딩·워터마크는 다). 나 는 캐릭터 1·2(도장이·떡순이)가 확정된 뒤 같은 선으로.

## 3. 색 규칙

- 털 주황 ≈ #D98B3A 계열(팔레트별로 조정) · 줄무늬 = `--ink` · 바다 = `--water` · 바탕 = `--paper`
- 눈·입 안 포인트만 고추장 **#B42318** — 빨강은 로고·맵기 도장·제보 버튼·호랑이 눈·입 외엔 쓰지 않음(슬랙 #design 10-28)
- 다크(먹밤)에서는 털을 한 단계 밝게, 줄무늬는 바탕색으로 뒤집음
