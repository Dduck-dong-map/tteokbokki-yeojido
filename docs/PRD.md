# 떡볶여지도 MVP PRD

## 1. 개요

**목적**: 내가 좋아하는 떡·스타일·맵기의 떡볶이를 파는 실제 가게를 지도에서 바로 골라 길찾기까지 가게 하고, 그 지도를 쓰는 사람들이 함께 채우고 고친다.
**대상 사용자**: 교회 청년부(3청) 가운데 떡볶이집을 가장 자주 찾는 1~3명(1차), 그다음 떡볶이 애호가(2차).
**운영 방식**: **「모두가 고치는 지도」**. 가입 없이 누구나 가게를 올리면 바로 지도에 나오고, 가 본 사람이 「맞아요·달라요」와 신고로 걸러 내며, 누구나 고치고 이력에 남는다. 운영자는 사전 승인 없이 어드민에서 가게를 직접 고치고 내리고 되살린다.

## 2. 문제 정의

청년부 사람들은 오늘 먹을 떡볶이집을 찾을 때 네이버·카카오 지도에서 「떡볶이」를 검색한다. 포털 지도로는 밀떡·쌀떡, 국물·즉석, 맵기 같은 취향으로 거를 수 없다.

## 3. 사용자 여정

```
1. 지도 홈 (모든 입구의 도착점, 가입 없음)
   ↓ 첫 진입: 대동여지도가 한양으로 확대되며 지도로 바뀜 (다른 화면 갔다 오면 다시 안 나옴)
   ↓ 폰: 처음에 위치 권한을 물음 / PC: 위치를 이미 허용했으면 묻지 않고 바로 내 위치 중심, 아니면 「내 위치」를 누를 때만 물음

   [허용]             → 내 위치 중심
   [거절 · 폰과 PC]   → 가게가 가장 많은 구의 가운데 (지금 강남구)
   ↓
   주변 가게 목록 「현재 지도에서 찾은 가게 N곳」 (위치 있으면 가까운순, 없으면 최근 확인순)

2. 지도 홈에서 고르기 (사용자 선택 분기)
   [검색창]   → 가게·동·주소로 찾음 (지도 범위와 상관없이, 필터는 유지) → 「검색으로 찾은 가게 N곳」
   [필터 버튼] → 필터 시트 「오늘은 어떤 떡?」 → 고를 때마다 맞는 가게 수 → [가게 N곳 보기]
   [목록 줄]   → 폰: 지도가 그 가게로 가고 줄이 선택됨 → 선택된 줄을 다시 누르면 가게 상세 / 768 이상: 바로 가게 상세
   [지도 도장] → 폰: 시트가 반쯤 올라오고 목록이 그 가게 줄로 스크롤 / 768 이상: 바로 가게 상세
   [등록 버튼] → 가게 등록

3. 가게 상세
   [네이버 지도로 길찾기] / [카카오맵] → 새 탭(네이버 = 가게 이름 + 주소 검색 결과, 카카오 = 좌표 길찾기) — 여정의 끝점, 누름 기록
   [아직 있어요]   → 200m 안이면 마지막 확인일 갱신
   [맞아요 · 달라요] → 등록 7일 안 「확인 중」 가게일 때만. 맞아요 3명 = 확인 끝 / 달라요가 서로 다른 접속 위치 3곳 = 지도에서 내림
   [평가 남기기]   → 별 + 한 줄 후기
   [정보 고치기]   → 정보 고치기 → 저장 즉시 반영 → 가게 상세
   [변경 이력]     → 변경 이력
   [신고]         → 이유 고르기 → 서로 다른 접속 위치 3곳이면 지도에서 내림
   [찜]           → 토스트 「찜했어요 · 내 맛지도 「찜한 가게」에 있어요」 (화면 이동 없음)
   [내 리스트에 담기] → 상세 안 펼침 칸(내 리스트 고르기 · 새 리스트) → [내 리스트 모두 보기] → 내 맛지도

4. 가게 등록 (폰 다섯 단계 / 768 이상 한 화면)
   가게·위치 → 떡·맛 → 메뉴·가격 → 소개글(선택) → 사진(선택)·닉네임 → 올리기
   ↓ 80m 안에 이름이 겹치는 가게(띄어쓰기를 빼고 대소문자를 무시했을 때 이름이 같거나 한쪽이 다른 쪽을 포함, 숨긴 가게 제외)?
     → 「이미 지도에 있는 가게 같아요: (가게 이름)」 → [그 가게 보기] 가게 상세 / [다른 가게예요] 계속
   ↓
   완료 「지도에 올렸어요」 → 가게 상세 (확인 중)

검색 유입: 검색엔진 → 지역·취향 목록 → 가게 상세 (뒤로 → 동네 목록)
아래 메뉴: 지도 · 떡볶이방 · 내 맛지도
   떡볶이방 → 떡볶이방 글 / 글쓰기
   내 맛지도 → 맛집 리스트
운영자: 어드민 로그인 → 가게 관리 ⇄ 가게 편집 / 후보 가져오기 / 운영 기록

※ 실패·빈 상태
- 필터 결과 0곳 → 「조건에 맞는 가게가 없어요」 + [필터 초기화]
- 지도 범위 안 0곳(가게는 있음) → 「이 지도 안에는 가게가 없어요」 + [가게 N곳 모두 보기]
- 검색 결과 0곳 → [검색어 지우기]
- 없는 가게 주소 → 없는 가게 안내 + [지도로] → 지도 홈
- 내려간(숨김) · 문 닫은 가게 → 지도·목록에 안 나옴. 주소로 직접 열면 가게 상세가 열리고 맨 위에 내린 까닭별 안내, 내 리스트에 담기·맞아요·달라요 칸은 없음
  · 지도가 저절로 내릴 때 이력에 「내린 까닭」(달라요 / 신고)을 남기고, 안내는 이력의 마지막 숨김·폐업 줄을 따름
  · 신고로 문 닫음 「문을 닫았다는 신고가 쌓여 지도에서 내렸어요.」
  · 달라요로 숨김 「사실과 다르다는 의견이 쌓여 지도에서 내렸어요.」
  · 신고로 숨김 「신고가 쌓여 지도에서 내렸어요.」
  · 운영자가 폐업 처리 「운영자가 문을 닫은 것을 확인해서 지도에서 내렸어요.」
  · 운영자가 숨김 「운영자가 확인해서 지도에서 내렸어요.」
  · 「숨김」 상태인데 이력에 숨김·폐업 줄이 없고 달라요 수가 3 미만 「지금은 지도에서 내린 가게예요.」
- 내려간(숨김 · 문 닫은) 가게에 아직 있어요 · 맞아요 · 달라요 → 저장하지 않고 「지도에서 내린 가게라 지금은 확인을 받지 않아요」 / 평가 → 「지도에서 내린 가게라 지금은 평가를 받지 않아요」 / 정보 고치기는 받음
- 지도 불러오기 실패 → 지도 실패 안내, 가게 상세의 주소·길찾기는 그대로
- 아직 있어요: 200m 밖 → 「가게 근처 200m 안에서만 누를 수 있어요」 / 위치 권한 거절 → 「위치를 허용해야 누를 수 있어요」 / 한국 시간 같은 날 이미 누름 → 「오늘은 이미 확인해 주셨어요」
- 등록·고치기 한 사람 최근 24시간 10건 넘음 → 「오늘은 등록·수정을 많이 해 주셨어요. 내일 다시 부탁드려요」, 입력 유지
- 같은 접속 위치 전체 상한(최근 24시간 등록·고치기 50 · 글 50 · 댓글 150 · 리스트 50 · 사진 150) 넘음 → 「지금 쓰는 인터넷(와이파이)에서 오늘 등록·수정이 너무 많이 올라왔어요. 데이터로 바꾸거나 내일 다시 부탁드려요」 (글 · 댓글 · 리스트 · 사진은 「등록·수정이」 자리에 「글이」 · 「댓글이」 · 「리스트가」 · 「사진이」)
- 사진 한 사람 최근 24시간 30장 넘음 → 「오늘은 사진을 많이 올리셨어요. 내일 다시 부탁드려요」
- 사진 저장소 설정이 없는 Vercel 배포에서 사진 올리기 → 「지금은 사진을 올릴 수 없어요. 사진 없이 먼저 올려 주세요」
- 기기 표시 없이 온 모든 쓰기(등록 · 고치기 · 확인 · 신고 · 평가 · 길찾기 누름 · 글 · 댓글 · 지우기 · 리스트 만들기·고치기·지우기 · 추천 · 사진) → 저장하지 않고 「이 브라우저를 알아보는 표시가 함께 오지 않았어요. 화면을 새로 고친 뒤 다시 해 주세요」
- 등록 올리기 실패 → 입력 유지 + 다시 시도
- 어드민 열쇠 없음 → 그 자리에 잠김 안내 「운영 로그인이 필요해요」 + [운영 로그인] → 어드민 로그인
```

## 4. 기능 명세

### 4.1 MVP 핵심 기능 (Must)

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 떡볶이 지도 | 대동여지도 느낌 바탕 지도. 도장 핀 = 고추 개수 알약(테두리 = 맵기 색), 전문·분식집은 큰 도장·'메뉴에 있음'은 작은 도장, 180일 넘게 확인 안 된 가게는 흐린 도장(범례 「흐린 도장 = 반년 넘게 확인 안 됨」), 365일 넘은 가게는 안 보임. 15배부터 실제 지도(15~15.8 사이에 그림 지도가 사라짐). 네이버 키가 있으면 네이버, 없으면 OpenFreeMap 상세 지도 | 「찾기」의 출발점 | 지도 홈 |
| **F002** | 취향 필터 | 버튼 하나로 여는 선택 기능. 떡 7종 · 스타일 8종(여러 개) · 맵기 1~5 범위 · 1인분 가격(4천·5천·6천 원 이하) · 영업 중 · 혼밥 · '메뉴에 있음' 보기. 고를 때마다 맞는 가게 수, 필터 상태가 링크에 담겨 공유됨 | 「취향으로 거르기」 | 지도 홈 |
| **F003** | 주변 가게 목록 | 지도 범위 안 가게 목록(폰 아래 시트 · 768 이상 왼쪽 패널). 줄 = 이름 → 동·거리 → 떡·스타일 → 맵기 → 대표 가격 → 별점. 가까운순·최근 확인순(기본: 위치가 있으면 가까운순, 없으면 최근 확인순). 폰: 줄을 누르면 지도가 그 가게로 가고 줄이 선택되며, 선택된 줄을 다시 누르면 상세 · 도장을 누르면 시트가 반쯤 올라오고 그 줄로 스크롤. 768 이상: 줄·도장을 누르면 바로 상세 | 접속 직후 주변 가게 노출 | 지도 홈 |
| **F004** | 지역·취향 목록 | 동네(구)별, 구 × 떡·스타일별 가게 목록. 지도 없이 서버가 그려 검색엔진이 읽음. 최근 확인된 가게가 위. 아래 메뉴에는 없고 검색·주소로 들어옴 | 「마포구 쌀떡볶이」 같은 검색 유입 | 동네 목록, 지역·취향 목록 |
| **F005** | 가게 상세 정보 | 맵기 도장(누르면 맵기 표정) · 이름 · 떡·스타일 · 동·거리·영업 → 대표 가격(확인일) · 「맵기 3 · 신라면 정도 · 대표 메뉴 기준」 → 위치 지도(폰 작은 지도, PC 옆 큰 지도) → 주소 복사 → 길찾기 → 소개글 → 사진 → 메뉴판 → 가게 정보 → 평가 → 마지막 확인 → 함께 고치기. 내려간 가게(숨김 · 문 닫음)를 직접 열면 맨 위에 내린 까닭별 안내가 나오며, 까닭은 이력의 마지막 숨김·폐업 줄(운영자 줄인지, 「내린 까닭」이 달라요인지 신고인지)을 따름 | 방문 여부 판단 | 가게 상세 |
| **F006** | '아직 있어요' 확인 | 가게 200m 안에서만 누름. 거리는 기기 안에서 재고 위치는 서버로 안 보냄. 누르면 마지막 확인일이 오늘. 같은 사람(기기와 접속 위치가 모두 같음)·같은 가게·한국 시간 같은 날 1번. 위치 권한을 거절하면 누를 수 없음. 내려간 가게(숨김 · 문 닫음)는 받지 않음 | 오래된 정보·폐업 감소 | 가게 상세 |
| **F007** | 길찾기 연결 | 「네이버 지도로 길찾기」(크게) + 「카카오맵」(보조). 네이버는 가게 이름 + 주소 검색 결과, 카카오는 가게 좌표 길찾기를 새 탭 링크로 엶. 앱 전용 주소는 쓰지 않음(폰에서는 OS 가 앱으로 넘길 수 있음) | 기준 지표(주간 길찾기)의 끝점 | 가게 상세 |
| **F016** | 가게 등록 | 로그인 없이 자동 닉네임(바꿀 수 있음)으로 바로 공개. 필수: 이름·어떻게 파나요(등급)·주소와 핀·떡·스타일·맵기(대표 메뉴 기준)·대표 메뉴 가격. 선택: 소개글 500자(전화번호·링크 막음)·메뉴 5개·별점·영업시간·사진 5장(0장도 됨). 80m 안에 이름이 겹치는 가게(띄어쓰기를 빼고 대소문자를 무시했을 때 이름이 같거나 한쪽이 다른 쪽을 포함, 숨긴 가게 제외)가 있으면 중복 안내 「이미 지도에 있는 가게 같아요: (가게 이름)」. 한도는 정보 고치기와 합쳐 최근 24시간 한 사람 10건 · 같은 접속 위치 전체 50건, 사진은 최근 24시간 한 사람 30장 · 같은 접속 위치 전체 150장. 나가면 기기 안 임시 저장 | 사용자가 데이터를 채우는 고리 | 가게 등록 |
| **F017** | 맞아요·달라요 확인 | 등록 7일 안이고 「맞아요」 3명 미만이면 「확인 중」. 가 본 사람이 맞아요/달라요, 같은 사람(기기와 접속 위치가 모두 같음) 가게당 한 표. 맞아요 3명 = 확인 끝 + 마지막 확인일이 오늘(기기 기준, 같은 와이파이의 세 사람이면 확인 끝). 달라요가 서로 다른 접속 위치(IP) 3곳에서 오면 지도에서 내림. 같은 접속 위치에서 기기만 다른 달라요 3표로는 내려가지 않음(화면의 달라요 수는 표 수 그대로). 달라요로 내릴 때 이력의 숨김 줄에 「내린 까닭 보임 → 달라요」를 남김. 내려간 가게(숨김 · 문 닫음)는 맞아요·달라요를 받지 않음 | 사전 승인 없는 거름 장치 | 가게 상세 |
| **F018** | 정보 고치기·변경 이력 | 누구나 이름·주소·핀·등급·떡·스타일·맵기·메뉴·영업시간·이용·소개글을 고치고 사진을 더함. 저장 즉시 반영되고 마지막 확인일이 오늘로 바뀜, 바뀐 칸이 이력에(예: 맵기 3 · 신라면 정도 → 4 · 불닭볶음면 정도). 내려간 가게(숨김 · 문 닫음)도 정보 고치기는 받음. 변경 이력에는 지도가 저절로 내린 줄의 「내린 까닭」(달라요 / 신고)도 나옴. 한도는 등록과 합쳐 최근 24시간 한 사람 10건 · 같은 접속 위치 전체 50건, 사진은 최근 24시간 한 사람 30장 · 같은 접속 위치 전체 150장 | 「모두가 고치는 지도」의 갱신 칸 | 정보 고치기, 변경 이력, 가게 상세 |
| **F019** | 신고·자동 내림 | 가게 신고 이유 5개(문을 닫았어요 · 떡볶이를 안 팔아요 · 광고 같아요 · 엉뚱한 곳에 찍혀 있어요 · 부적절한 사진·글이 있어요). 신고가 서로 다른 접속 위치(IP) 3곳에서 오면 지도에서 내림(「문을 닫았어요」를 낸 접속 위치가 과반이면 「문 닫음」, 아니면 「숨김」)이고, 내릴 때 이력의 그 줄에 「내린 까닭 보임 → 신고」를 남김. 「문 닫음」은 어드민 화면에 「폐업」으로 표시됨. 같은 접속 위치에서 기기만 다른 신고 3건으로는 내려가지 않음. 같은 사람(기기와 접속 위치가 모두 같음)은 가게당 한 번. 후기는 신고가 서로 다른 접속 위치 3곳에서 오면 숨김. 내림은 지우지 않음 | 나쁜 등록의 사후 거름 | 가게 상세 |
| **F020** | 평가 | 별 1~5(필수) + 한 줄 후기 80자. 같은 사람(기기와 접속 위치가 모두 같음) 가게당 하나(다시 쓰면 바뀜). 맵기는 평가에서 받지 않고 정보 고치기에서 고침. 내려간 가게(숨김 · 문 닫음)는 평가를 받지 않음 | 주관적인 맛에 대한 리뷰 | 가게 상세 |
| **F021** | 가게 검색 | 가게 이름·동·주소로 찾음. 지도 범위와 상관없이 찾고 걸어 둔 필터는 유지(폰 검색창 · 768 이상 위 헤더) | 「검색 → 선택 → 상세 → 길찾기」 흐름 | 지도 홈 |

## 5. 수용 기준

### F001 떡볶이 지도
- **Given** 맵기 3인 가게와 마지막 확인 200일 전 가게가 있다 **When** 지도 홈을 연다 **Then** 앞 가게는 고추 3개 알약, 뒤 가게는 흐린 도장으로 보이고 「흐린 도장 = 반년 넘게 확인 안 됨」 범례가 나온다
- **Given** 마지막 확인이 400일 전인 가게 **When** 그 가게가 있는 곳으로 지도를 옮긴다 **Then** 도장이 없다
- **Given** 지도 타일을 못 받는다 **When** 지도 홈을 연다 **Then** 지도 실패 안내가 뜨고 빈 지도만 남지 않는다

### F002 취향 필터
- **Given** 지도 홈 **When** 필터에서 떡 「쌀떡」·맵기 2~4 를 고른다 **Then** 버튼에 조건에 맞는 가게 수가 나오고, 그 링크를 새 창에서 열면 같은 조건이 걸려 있다
- **Given** 맞는 가게가 0곳인 조합 **When** 고른다 **Then** 「조건에 맞는 가게가 없어요」와 [필터 초기화]가 보이고, 누르면 모든 조건이 풀린다

### F003 주변 가게 목록
- **Given** 위치 허용, 지도 범위 안 가게 5곳 **When** 지도 홈을 연다 **Then** 「현재 지도에서 찾은 가게 5곳」 아래 5줄이 가까운순으로 나오고, 「최근 확인순」을 누르면 마지막 확인일 순으로 바뀐다
- **Given** 위치 없음(거절 또는 PC에서 묻지 않음) **When** 지도 홈을 연다 **Then** 목록이 최근 확인순으로 나온다
- **Given** 폰 폭 390 **When** 목록 줄을 한 번 누른다 **Then** 지도가 그 가게로 가고 줄이 선택되며, 같은 줄을 다시 누르면 가게 상세가 열린다. 폭 768 이상에서는 한 번 누르면 바로 가게 상세가 열린다
- **Given** 지도 범위 안 0곳, 전체 12곳 **When** 지도를 빈 곳으로 옮긴다 **Then** 「이 지도 안에는 가게가 없어요」와 [가게 12곳 모두 보기]가 나온다

### F004 지역·취향 목록
- **Given** 마포구에 쌀떡 가게 3곳 **When** 검색엔진 결과로 마포구 쌀떡 목록에 들어온다 **Then** 지도 없이 3곳이 최근 확인순으로 보이고 누르면 가게 상세로 간다
- **Given** 서대문구에 가게 0곳 **When** 동네 목록을 연다 **Then** 서대문구 칩에 「0곳」이 보이고, 칩을 누르면 지역·취향 목록에 「아직 등록된 가게가 없어요. 아는 집을 등록해 주세요!」가 나온다

### F005 가게 상세 정보
- **Given** 폰 폭 390 **When** 가게 상세를 열고 작은 위치 지도 위를 위아래로 민다 **Then** 페이지가 스크롤되고, 누르면 지도 홈이 그 가게 중심으로 열린다
- **Given** PC 폭 1280 **When** 가게 상세 링크로 바로 들어온다 **Then** 목록 + 상세 + 큰 지도가 보이고 큰 지도가 그 가게 중심이다
- **Given** 없는 가게 주소 **When** 연다 **Then** 없는 가게 안내와 [지도로]가 나온다
- **Given** 서로 다른 접속 위치 3곳의 신고로 「문 닫음」이 된 가게 **When** 그 가게 주소로 직접 연다 **Then** 가게 상세 맨 위에 「문을 닫았다는 신고가 쌓여 지도에서 내렸어요.」가 나오고 내 리스트에 담기 칸이 없다
- **Given** 달라요로 내려간 가게 / 신고로 숨겨진 가게 / 운영자가 폐업 처리한 가게 / 운영자가 숨긴 가게 **When** 그 가게 주소로 직접 연다 **Then** 맨 위에 「사실과 다르다는 의견이 쌓여 지도에서 내렸어요.」 / 「신고가 쌓여 지도에서 내렸어요.」 / 「운영자가 문을 닫은 것을 확인해서 지도에서 내렸어요.」 / 「운영자가 확인해서 지도에서 내렸어요.」가 나온다
- **Given** 같은 접속 위치의 달라요 3표(내려가지 않음) 뒤에 서로 다른 접속 위치 3곳의 신고로 숨겨진 가게 **When** 그 가게 주소로 직접 연다 **Then** 맨 위 안내는 달라요 수와 상관없이 이력의 「내린 까닭」을 따라 「신고가 쌓여 지도에서 내렸어요.」다
- **Given** 「숨김」 상태인데 이력에 숨김·폐업 줄이 없고 달라요 수가 3 미만인 가게 **When** 그 가게 주소로 직접 연다 **Then** 맨 위에 「지금은 지도에서 내린 가게예요.」가 나온다

### F006 '아직 있어요' 확인
- **Given** 가게에서 150m **When** 「아직 있어요」를 누른다 **Then** 「확인 고마워요!」가 뜨고 마지막 확인일이 오늘로 바뀐다
- **Given** 가게에서 500m / 오늘 이미 누름 **When** 누른다 **Then** 「가게 근처 200m 안에서만 누를 수 있어요」 / 「오늘은 이미 확인해 주셨어요」가 뜨고 확인일은 그대로다
- **Given** 위치 권한 거절 **When** 「아직 있어요」를 누른다 **Then** 「위치를 허용해야 누를 수 있어요」가 뜨고 확인일은 그대로다
- **Given** 신고로 내려간 가게(숨김 또는 문 닫음) **When** 「아직 있어요」를 보낸다 **Then** 「지도에서 내린 가게라 지금은 확인을 받지 않아요」가 뜨고 확인일은 그대로다

### F007 길찾기 연결
- **Given** 가게 상세 **When** 「네이버 지도로 길찾기」를 누른다 **Then** 새 탭에 네이버 지도가 「가게 이름 + 주소」 검색 결과로 열린다
- **Given** 가게 상세 **When** 「카카오맵」을 누른다 **Then** 새 탭에 카카오맵이 그 가게 이름과 좌표를 도착지로 한 길찾기로 열린다
- **Given** 지도 앱이 없는 폰 **When** 두 버튼 가운데 하나를 누른다 **Then** 같은 링크가 브라우저의 지도 웹으로 열린다(앱이 있으면 OS 가 앱으로 넘길 수 있다)

### F016 가게 등록
- **Given** 필수 칸을 모두 채우고 사진 0장 **When** 올린다 **Then** 「지도에 올렸어요」가 뜨고 지도·목록에 「확인 중」 배지와 함께 바로 나온다
- **Given** 80m 안에 「신당 떡볶이」가 있다 **When** 「신당떡볶이 본점」을 올린다 **Then** 「이미 지도에 있는 가게 같아요: 신당 떡볶이」가 뜨고 [그 가게 보기] / [다른 가게예요] 중 고를 수 있으며, [다른 가게예요]를 누르면 올라간다
- **Given** 80m 안에 이름이 겹치는 가게가 숨김 상태다 / 이름이 겹치는 가게가 80m 밖에 있다 **When** 올린다 **Then** 중복 안내 없이 올라간다
- **Given** 소개글에 전화번호 / 최근 24시간 안 11번째 등록·고치기 **When** 올린다 **Then** 「소개글에는 전화번호를 넣을 수 없어요」 / 「오늘은 등록·수정을 많이 해 주셨어요. 내일 다시 부탁드려요」가 뜨고 입력은 그대로 남는다
- **Given** 같은 접속 위치에서 최근 24시간 등록·고치기가 50건 찼다 **When** 그 접속 위치의 다른 기기로 올린다 **Then** 「지금 쓰는 인터넷(와이파이)에서 오늘 등록·수정이 너무 많이 올라왔어요. 데이터로 바꾸거나 내일 다시 부탁드려요」가 뜨고, 다른 접속 위치에서는 올라간다
- **Given** 최근 24시간 사진 30장을 올린 사람 **When** 31번째 사진을 올린다 **Then** 「오늘은 사진을 많이 올리셨어요. 내일 다시 부탁드려요」가 뜨고 사진은 저장되지 않는다

### F017 맞아요·달라요 확인
- **Given** 등록 3일 된 확인 중 가게, 맞아요 2 **When** 다른 기기가 「맞아요」를 누른다(앞의 두 사람과 같은 접속 위치여도 됨) **Then** 「확인 중」 배지가 사라지고 마지막 확인일이 오늘로 바뀐다
- **Given** 같은 기기·같은 접속 위치 **When** 같은 가게에 두 번째로 누른다 **Then** 「이미 알려 주셨어요. 고마워요!」가 뜨고 표가 늘지 않는다
- **Given** 확인 중 가게 **When** 서로 다른 접속 위치 3곳에서 「달라요」가 온다 **Then** 그 가게는 지도에서 내려간다
- **Given** 확인 중 가게 **When** 같은 접속 위치에서 기기만 다른 「달라요」 3표가 온다 **Then** 달라요 수는 3이 되지만 가게는 내려가지 않는다
- **Given** 등록 7일 안에 신고로 내려간 가게(숨김 또는 문 닫음) **When** 「맞아요」 또는 「달라요」를 보낸다 **Then** 「지도에서 내린 가게라 지금은 확인을 받지 않아요」가 뜨고 상태 · 표 수 · 이력이 그대로다

### F018 정보 고치기·변경 이력
- **Given** 맵기 3인 가게 **When** 정보 고치기에서 4로 바꿔 저장한다 **Then** 상세 도장이 4가 되고 마지막 확인일이 오늘로 바뀌며 변경 이력에 「맵기 3 · 신라면 정도 → 4 · 불닭볶음면 정도」가 남는다
- **Given** 대표 메뉴 이름을 비움 **When** 저장한다 **Then** 「대표 메뉴 이름을 넣어 주세요」가 뜨고 저장되지 않는다
- **Given** 최근 24시간 등록·고치기 10건을 한 사람 **When** 정보 고치기를 저장한다 **Then** 「오늘은 등록·수정을 많이 해 주셨어요. 내일 다시 부탁드려요」가 뜨고 저장되지 않는다
- **Given** 신고로 내려간 가게 **When** 정보 고치기에서 맵기를 바꿔 저장한다 **Then** 저장된다
- **Given** 서로 다른 접속 위치 3곳의 달라요로 내려간 가게 **When** 변경 이력을 연다 **Then** 맨 위 줄이 「지도」의 「의견이 쌓여 지도에서 내렸어요」이고 그 아래에 「내린 까닭 보임 → 달라요」가 나온다

### F019 신고·자동 내림
- **Given** 서로 다른 접속 위치 3곳 **When** 같은 가게를 「문을 닫았어요」로 신고한다 **Then** 그 가게가 지도·목록에서 빠지고 가게 관리에 「폐업」 배지로 남으며, 운영 기록에 「지도」의 「폐업」 줄과 「내린 까닭 보임 → 신고」가 남는다
- **Given** 같은 접속 위치에서 기기만 다른 신고 3건 **When** 3번째 신고가 들어온다 **Then** 가게는 지도·목록에 그대로 남는다
- **Given** 한 줄 후기 신고가 서로 다른 접속 위치 2곳 **When** 2번째 신고가 들어온다 **Then** 후기는 그대로 남는다(서로 다른 접속 위치 3곳이 되면 숨김)
- **Given** 이미 이 가게를 신고한 같은 사람 **When** 다시 신고한다 **Then** 「이미 신고해 주셨어요. 고마워요!」가 뜨고 신고 수는 그대로다

### F020 평가
- **Given** 가게 상세 **When** 별 없이 후기만 쓰고 올린다 **Then** 「별점을 골라 주세요」가 뜨고 올라가지 않는다
- **Given** 이미 별 3을 남긴 같은 사람 **When** 별 5로 다시 올린다 **Then** 평가가 한 개로 유지되고 값만 5로 바뀐다
- **Given** 신고로 내려간 가게(숨김 또는 문 닫음) **When** 평가를 올린다 **Then** 「지도에서 내린 가게라 지금은 평가를 받지 않아요」가 뜨고 별점과 후기 수는 그대로다

### F021 가게 검색
- **Given** 지도를 강남구로 확대해 둠 **When** 검색창에 「망원」을 친다 **Then** 「검색으로 찾은 가게 N곳」에 망원동 가게가 나온다
- **Given** 맞는 가게 없음 **When** 검색한다 **Then** 빈 안내와 [검색어 지우기]가 나온다

### F010 어드민 열쇠
- **Given** 열쇠가 정해진 배포 **When** 열쇠 없이 가게 관리를 연다 **Then** 다른 화면으로 옮기지 않고 그 자리에 「운영 로그인이 필요해요」와 [운영 로그인] 단추가 나오며, 단추로 간 어드민 로그인에서 맞는 열쇠를 넣으면 가게 관리가 열린다
- **Given** 열쇠를 안 정함 **When** 같은 와이파이의 폰으로, 또는 운영 모드(production)로 띄운 서버에서 어드민을 연다 **Then** 「이 주소에서는 운영 화면이 잠겨 있어요」가 나온다
- **Given** 열쇠 없음 **When** 시안 화면(홈 · 제보 · 신고 · 설정 · 신선도 점검)을 연다 **Then** 내용 대신 같은 잠김 안내가 나온다
- **Given** 열쇠 없음 **When** 홈 또는 가게 관리를 연다 **Then** 머리칸에는 제목과 설명만 나오고 「승인 시작」 · 「자료 넣기」 · 「직접 등록」은 나오지 않으며, 누를 수 있는 것은 잠김 안내의 [운영 로그인] 단추뿐이다

### F012 가게 관리
- **Given** 신고로 내려간 가게 **When** 가게 편집에서 「되살리기」를 누른다 **Then** 지도에 다시 나오고 운영 기록에 「수정」 줄(상태 폐업 또는 숨김 → 보임)이 남는다
- **Given** 지도에 올라가 있는 가게 **When** 가게 편집에서 「폐업 처리」를 한다 **Then** 지도·목록에서 빠지고 가게 관리에 「폐업」 배지가 붙으며 운영 기록에 「폐업」 줄(상태 보임 → 폐업, 고른 사유가 뒤에 붙음)이 남는다
- **Given** 되살린 가게 **When** 새 접속 위치 1곳이 신고한다 / 되살리기 전에 신고한 사람이 다시 신고한다 **Then** 가게는 그대로 올라가 있다 / 「이미 신고해 주셨어요. 고마워요!」가 뜬다. 되살린 뒤 서로 다른 접속 위치 3곳의 신고가 새로 쌓이면 다시 내려간다
- **Given** 달라요로 내려간 가게 **When** 되살린다 **Then** 달라요 수가 0이 되고, 그 뒤 달라요 1표로는 내려가지 않는다
- **Given** 가게 편집에서 스타일을 비움 **When** 저장한다 **Then** 저장되지 않고 그 칸이 표시된다

### F015 길찾기 누름 기록
- **Given** 같은 사람이 같은 가게 **When** 오늘 「네이버 지도로 길찾기」를 두 번 누른다 **Then** 기록은 한 줄이다
- **Given** 기록 저장이 실패 **When** 길찾기를 누른다 **Then** 길찾기 링크는 그대로 열린다

### F022 후보 가져오기
- **Given** 마포 v1 자료(빈 칸 없는 14곳 · 빈 칸 5곳) **When** 「넣을 수 있는 14곳 모두 넣기」 **Then** 14곳이 들어가고 이력에 14줄이 남는다
- **Given** 이미 DB 에 있는 가게 id **When** 다시 넣는다 **Then** 덮어쓰지 않는다

### F023 운영 기록
- **Given** 운영자가 가게 하나를 고침 **When** 운영 기록을 연다 **Then** 맨 위에 그 변경이 시각·종류와 함께 나온다
- **Given** 기록 0건 **When** 연다 **Then** 「아직 남은 기록이 없어요」와 「가게를 등록하거나 고치면 여기에 한 줄씩 쌓여요.」가 나온다
- **Given** 가게 한 곳만 보기 **When** 운영 기록을 연다 **Then** 그 가게의 기록만 나오고, 0건이면 「아직 남은 기록이 없어요」와 「이 가게는 아직 등록·수정·확인 기록이 없어요.」가 나온다

### F024 찜·내 등록
- **Given** 가게 상세 **When** 찜 단추(하트 아이콘)를 누른다 **Then** 「찜했어요 · 내 맛지도 「찜한 가게」에 있어요」가 뜨고 내 맛지도 찜한 가게에 그 가게가 있다
- **Given** 다른 브라우저 **When** 내 맛지도를 연다 **Then** 찜·내 등록이 비어 있다

### F025 맛집 리스트
- **Given** 「링크로만 공유」 리스트 **When** 다른 사람이 링크로 연다 **Then** 지도에 도장 + 번호로 보이지만 「모두의 리스트」에는 없다
- **Given** 남이 만든 리스트 **When** 고치려 한다 **Then** 고칠 수 없다. 내 리스트에서는 추천 단추가 꺼져 있어 눌리지 않고, 단추 설명이 「내 리스트는 추천할 수 없어요」다
- **Given** 최근 24시간 리스트 20개를 만든 사람 / 같은 접속 위치에서 리스트 50개가 찼다 **When** 새 리스트를 만든다 **Then** 「오늘은 리스트를 많이 만들어 주셨어요. 내일 다시 부탁드려요」 / 「지금 쓰는 인터넷(와이파이)에서 오늘 리스트가 너무 많이 올라왔어요. 데이터로 바꾸거나 내일 다시 부탁드려요」가 뜨고 만들어지지 않는다
- **Given** 최근 24시간 안에 리스트 만들고 지우기를 20번 되풀이한 사람 **When** 새 리스트를 만든다 **Then** 「오늘은 리스트를 많이 만들어 주셨어요. 내일 다시 부탁드려요」가 뜨고 만들어지지 않는다(지운 것도 한도에 셈)

### F026 떡볶이방 게시판
- **Given** 글쓰기 **When** 말머리 「같이 가요」 + 제목 + 내용 + 가게를 붙여 올린다 **Then** 떡볶이방 목록 맨 위에 보이고 글에 그 가게 링크가 있다
- **Given** 제목 없음 / 서로 다른 접속 위치 3곳이 신고 **When** 올림 / 집계됨 **Then** 「제목을 써 주세요」 / 글이 가려진다
- **Given** 떡볶이방 글의 남의 댓글 / 이 기기에서 쓴 댓글 **When** 서로 다른 접속 위치 3곳이 신고 / 지우기를 누름 **Then** 댓글이 가려지고 댓글 수가 줄어든다 / 댓글이 지워진다
- **Given** 글 또는 댓글 **When** 같은 접속 위치에서 기기만 다른 신고 3건이 온다 **Then** 글·댓글은 가려지지 않는다
- **Given** 최근 24시간 글 20개를 쓴 사람 / 같은 접속 위치에서 글 50개가 찼다 **When** 글을 올린다 **Then** 「오늘은 글을 많이 써 주셨어요. 내일 다시 부탁드려요」 / 「지금 쓰는 인터넷(와이파이)에서 오늘 글이 너무 많이 올라왔어요. 데이터로 바꾸거나 내일 다시 부탁드려요」가 뜨고 올라가지 않는다
- **Given** 최근 24시간 댓글 60개를 쓴 사람 / 같은 접속 위치에서 댓글 150개가 찼다 **When** 댓글을 올린다 **Then** 「오늘은 댓글을 많이 써 주셨어요. 내일 다시 부탁드려요」 / 「지금 쓰는 인터넷(와이파이)에서 오늘 댓글이 너무 많이 올라왔어요. 데이터로 바꾸거나 내일 다시 부탁드려요」가 뜨고 올라가지 않는다
- **Given** 최근 24시간 안에 글 쓰고 지우기를 20번 / 댓글 쓰고 지우기를 60번 되풀이한 사람 **When** 글 / 댓글을 올린다 **Then** 「오늘은 글을 많이 써 주셨어요. 내일 다시 부탁드려요」 / 「오늘은 댓글을 많이 써 주셨어요. 내일 다시 부탁드려요」가 뜨고 올라가지 않는다(지운 것도 한도에 셈). 쓴 지 24시간이 지나면 한도에서 빠진다

## 8. 데이터 모델

표는 `db/init/001_schema.sql` · `004_directions.sql` 의 13개이며, 파일 저장소도 같은 구조다. device · ip 는 해시값이다. 「한 사람 한 번」(맞아요·달라요 한 표, 신고 한 번, 평가 하나, 아직 있어요 하루 한 번)과 한 사람 하루 한도의 같은 사람은 device 와 ip 가 **모두** 같을 때다. 내리는 판정(달라요 · 가게 신고)과 가림(후기 · 글 · 댓글 신고)은 서로 다른 ip 수가 3 이상일 때이고, 「문 닫음」 과반도 ip 수로 센다. 맞아요 3명(확인 끝)은 표 수로 센다. 같은 접속 위치 전체 하루 상한은 ip 만 같으면 함께 센다. 글 · 댓글 · 리스트의 하루 한도는 최근 24시간 안에 쓴 것을 지운 것(deleted_writes)까지 포함해 센다. 운영자가 되살린 가게는 되살린 시각(store_logs 의 「상태 → 보임」 줄) 뒤에 들어온 신고·달라요만 센다. 태그 값은 `taxonomy.ts` 의 정해진 보기만 쓴다.

## 10. 기술 스택

- **Next.js 16.4.6** (App Router · Cache Components) — 화면 = 컨테이너 + View, 지역·취향 목록은 서버에서 그림

## 11. 범위 밖

### 11.1 MVP 이후 (Should · Could)
- 등록 검토함(확인함·고치기·내리기·합치기·한꺼번에 되돌리기)
- 어드민 홈 「오늘 할 일」 · 신고·요청함 · 신선도 점검 · 설정(규칙 숫자·금칙어·기기 차단) · 글·사진 관리 · 가게 잠금 — 시안 단계, 실제 데이터 미연결
- 사장님·권리 침해 요청 창구 — 현재 창구 없음
- 캡차 — 현재 없음
- 이용약관 · 개인정보 처리방침 — 현재 페이지 없음
- 사진 1장 필수로 되돌리기 — 사진 저장소 연결 후(`MIN_PHOTOS` 0 → 1)
- 주소 검색(도로명주소) · 상호 검색(이름 → 주소) — 키·약관 확인 필요
- 역에서 걷는 어림 시간 「합정역에서 걸어서 약 3분」 — 역 좌표 자료 필요
- 등록 시작·단계·완료 기록 — 현재는 길찾기만 측정
- 「같이 가요」 글마다 가게 1곳 등록 잇기 — 핀 먼저 · 기능 동결 결과를 보고 켤 후보

### 11.2 이번에 하지 않는 것 (Won't)
- 운영자 사전 승인이 기본인 제보 — 바로 공개 + 사후 검증으로 대체
- 가격·맵기 「다른 2명 동의」 자동 반영 · 같은 제보 3건 우선 검토 — 사전 승인 구조와 함께 폐기
- 메뉴별 맵기 — 메뉴마다 맵기가 달라 구조 변경 필요
- 이용자 로그인 · 크루 역할 — 로그인 없음, 크루 없음
- 포인트(어묵 쓰임) · 순위 · 쿠폰 · 핫딜 · 쇼핑 적립 · 팝업·전면 광고 — 1차는 지도 고리에 집중
- 떡지순례 도장 · 사장님 센터 · 밀키트 · 배달 주문 연결 · 앱 · 걷는 길 선 — 2·3차 또는 고리 밖
- 공공데이터 인허가 후보 적재 — 첫 가게는 리서치 자료 묶음으로 입력

## 12. 열린 질문

1. **팀 기획안과 다른 여섯 곳의 확정** — ① 커뮤니티 2차 → 떡볶이방·리스트 포함(F025·F026) ② 어드민 추후 → 가게 관리 앞당김(F012·F022·F023) ③ 별 + 맵기 두 축 → 맵기 투표 보류(F020) ④ 운영자 승인 → 바로 공개(F016~F019) ⑤ 상세 첫 칸 「이름 → 위치 → 종류 → 맵기 → 가격 → 길찾기」 → 「이름·종류·맵기 → 동·거리·영업 → 가격 → 위치 지도 → 길찾기」. 선택지: 현재 구현 유지 / 기획대로 되돌림. ⑥ 「승인 후 공개」 스위치 — 선택지: MVP 이후 / 지금 만듦.
2. **배포 때 여는 구와 가게 수** — 선택지: 「첫 300곳」 / 청년부 동선 30~50곳 / 현재 실제 가게 36곳(강남 22 · 마포 14, 마포 자료 19곳 중 14곳 입력). 서대문구는 동네 칩만 있고 가게가 없다.
3. **'아직 있어요' 거리 200m(`NEAR_M`) 확정** — 선택지: 200m 확정 / 다른 거리.
4. **성공 지표 목표 값** — 주간 새 등록·고치기: 주 50건 / 다른 값. 7일 안 내려간 등록 비율: 10% 이하 / 다른 값.
5. **어드민 메뉴의 시안 항목(홈 · 제보 · 신고 · 설정 · 신선도 점검)** — 선택지: 배포에서도 보임 / 배포에서 숨김.
