# 떡볶여지도 서비스 기획안 (v5)

## 1. 서비스 개요

떡볶여지도는 "오늘 어떤 떡볶이가 당기는지"를 출발점으로 동네 분식 맛집을 지도에서 찾게 해 주는 웹 서비스입니다. 거지맵이 '가격'을 기준으로 지도를 걸렀다면, 떡볶여지도는 '떡볶이 취향(떡·소스·맵기·스타일)'을 기준으로 거릅니다.

- **한 줄 정의:** 떡 종류와 맵기까지 골라 찾는 전국 분식 맛집 지도
- **이름의 뜻:** '떡볶이 + 여기 + 지도'. 지도 핀을 떡볶이 그릇 모양으로 두면 이름이 화면에서 바로 읽힙니다.
- **핵심 가치 세 가지**
  1. 취향으로 찾기: 밀떡/쌀떡, 국물/즉석/짜장, 맵기 1\~5단계로 거르는 지도
  2. 믿을 수 있는 최신 정보: 사용자 제보 + 최근 확인일 표시 + 폐업·가격 변동 신고
  3. 동네 노포 발굴: 프랜차이즈가 아닌 학교 앞·시장 분식집을 지도에 올리는 재미
- **1차 목표(출시 후 6개월):** 서울·수도권 분식집 1,500곳 등록, 월 이용자 3만 명, 월 제보 1,000건

목표 수치는 기획 단계의 가정치이며, 출시 전 베타 결과로 다시 정합니다.

**목적과 목표(v5, 팀 피드백 10-28)**

- 목적: 팀장 추천 — 동아리(팀) 안에서 먼저 쓰이고 추천받는 지도.
- 1차 목표: 「3청」의 미식 지도로 쓰이기(원문 그대로. 「3청」이 조직 이름인지 삼청동인지 확인 필요).
- 2차 목표: 떡볶이 애호가의 지도.
- 1차 완성 범위는 **맛집 탐색 · 가게 상세 · 길찾기 · 제보**를 불편 없이 쓰는 수준(5절). 캐릭터 확장 · 자동화 · 운영 통계 · 어드민은 추후.

## 2. 모티브 사이트 분석: 거지맵

[거지맵](https://xn--v69ak0xskm.com/)(거지맵.com)은 "지도 기반으로 가성비 식당 정보를 찾고, 익명 제보로 최신 가격 정보를 공유"하는 서비스입니다. 카카오톡 오픈채팅 '거지방'에서 시작해 개인 개발자가 AI 코딩 도구로 지도 API 웹페이지를 만들었고, 당근 입소문으로 퍼져 구글 플레이 다운로드 1만 건을 넘겼습니다([위키트리, 2026-05-26](https://www.wikitree.co.kr/articles/1138410)). 혼자 만든 지도 하나가 주제 하나로 크게 퍼질 수 있다는 점이 떡볶여지도에 가장 중요한 근거입니다.

| 메뉴 | 역할 | 확인한 내용 |
| --- | --- | --- |
| 식당 지도 (/) | 메인. 지도에서 가게 핀을 눌러 메뉴·가격 확인 | 회원가입 없이 사용, 앱 설치 불필요 |

| [거지방](https://xn--v69ak0xskm.com/bang) | 커뮤니티 게시판 | "절약 팁과 식당 후기" 공유 |
| 핫딜 | 생활비 절약 정보 | 상세 구성은 확인 못 함 |

**가져올 점**

- 가입 없이 바로 지도: 처음 온 사람이 3초 안에 가게를 본다.
- 익명 제보 + 수정 가능: 이용자가 "직접 업데이트하고 부정확한 내용을 고칠 수 있다"는 점을 가장 많이 칭찬함.
- 지역·가격·메뉴별 SEO 목록 페이지: '마포구 떡볶이 맛집' 같은 검색어를 받는 구조.
- 커뮤니티에서 출발한 말투와 재미(거지방·티끌 같은 이름 붙이기).

**바꿀 점**

- 가격만 보여 맛·위생은 직접 확인해야 한다는 후기가 많다 → 떡볶여지도는 '맛 태그'가 주인공.
- 폐업·가격 변동이 늦게 반영된다는 지적 → '마지막 확인일'과 확인 요청 알림을 기본으로.
- 쇼핑 적립·핫딜은 주제와 멀다 → 떡볶이 밀키트·맛집 예약처럼 주제에 맞는 수익만 붙인다.
- 여러 블로그가 주소를 제각각 안내해 혼동이 있다 → 영문 도메인을 함께 확보한다.

## 3. 시장·경쟁 리서치

떡볶이는 이미 큰 외식 분야이지만, '떡볶이만 다루는 지도'는 인스타 개인 계정 수준에 머물러 빈자리입니다. 국내 떡볶이 프랜차이즈는 약 150개이고, 엽기떡볶이 점포 평균 매출(2024년 8억 8천만 원)이 교촌치킨보다 높을 만큼 커졌습니다([아시아경제, 2025-11-07](https://view.asiae.co.kr/article/2025110616251003201)).

| 브랜드 | 점포 수 흐름 | 시사점 |
| --- | --- | --- |
| 신전떡볶이 | 722곳(2022) → 818곳(2025년 10월) | 저렴한 동네 분식 수요는 꾸준하다 |
| 엽기떡볶이 | 552곳(2022) → 659곳(2024) | 맵기 6단계·팬 마케팅이 통한다 → 맵기 태그의 근거 |
| 배떡 | 490곳(2022) → 325곳(2024) | 로제 열풍이 식으면서 줄었다 → 유행 맛은 빨리 바뀜다 |
| 청년다방 | 356곳 | 카페형 분식으로 20\~30대 직장인 공략 |

**경쟁·대체 서비스**

| 서비스 | 떡볶이를 찾을 때 강점 | 빈틈 |
| --- | --- | --- |
| 네이버 지도·카카오맵 | 가게 수, 길찾기, 리뷰 양 | 떡 종류·맵기로 못 거름. 프랜차이즈가 목록을 덮음 |
| 배달 앱 | 주문까지 한 번에 | 배달 가능한 가게만. 포장·매장 노포는 빠짐 |
| [거지맵](https://xn--v69ak0xskm.com/) | 가입 없는 지도, 제보 문화 | 가격 기준이라 맛 취향 정보 없음 |
| 인스타 '떡지순례' 계정 | 떡 종류·맵기를 꼼꼼히 표기, 책 출간([GQ](https://www.gqkorea.co.kr/2022/11/14/%EB%A9%94%EB%89%B4-%ED%95%98%EB%82%98%EB%A7%8C-%EC%A7%91%EC%A4%91-%EC%86%8C%EA%B0%9C%ED%95%98%EB%8A%94-%EB%A7%9B-%EB%8D%95%ED%9B%84-%EA%B3%84%EC%A0%95-5)) | 한 사람의 기록이라 검색·거리 기반 탐색 불가 |
| 나만의 지도 앱(머핀 등) | 떡볶이 덕질을 지도로 정리([디아이투데이](https://ditoday.com/?p=16327)) | 주제 범용이라 떡볶이용 분류 없음 |

결론: 떡지순례 같은 덕후의 표기 방식(떡·맵기)을 거지맵 같은 열린 제보 지도에 옮기면, 포털 지도가 못 하는 일을 합니다. 떡볶이 시장 전체 금액은 공개 자료에서 찾지 못해, 투자·제휴 제안서가 필요하면 aT 식품산업통계를 따로 확인해야 합니다.

유사 서비스 20곳 조사는 [시장조사](시장조사_v1_2026-10-25.md) 탭에 있습니다. 떡 종류·맵기로 거르고 익명 제보로 채우는 떡볶이 지도는 국내외 어디에서도 찾지 못했고, 5·7·10·11절을 그 조사로 고쳤습니다(2026-10-25).

## 4. 타깃과 문제 정의

핵심 문제는 "내가 좋아하는 스타일의 떡볶이를 파는 가게를 지도 앱에서 골라낼 수 없다"입니다. 지금은 SNS에서 찾고 지도 앱에서 다시 확인하는 두 단계를 거치는데, 거지맵은 이 두 단계를 하나로 줄여 인기를 얻었습니다([위키트리](https://www.wikitree.co.kr/articles/1138410)).

| 페르소나 | 상황 | 원하는 것 | 핵심 기능 |
| --- | --- | --- | --- |
| 떡덕 지수(27세, 직장인) | 주말마다 떡볶이 탐방, 인스타에 기록 | 못 가 본 쌀떡·국물 떡볶이집, 도장 모으기 | 취향 필터, 방문 도장, 내 지도 공유 |
| 학교 앞 민준(16세, 고등학생) | 하교길 용돈 5천 원 | 가까운 곳, 1인분 가격 | 내 주변 지도, 가격대 필터 |
| 점심 고민 현우(34세, 외근직) | 처음 가는 동네, 혼자 식사 | 혼밥 되는지, 지금 영업 중인지 | 영업 중 필터, 혼밥·포장 태그 |
| 동네 사장님(52세, 시장 분식집) | 단골은 있지만 온라인에 없음 | 손님이 찾아오기, 정보 직접 고치기 | 사장님 인증, 가게 정보 관리 |

1차 집중 대상은 '떡덕 지수'입니다. 제보와 공유를 가장 많이 하는 층이고, 이들이 쌓은 정보가 나머지 세 페르소나를 끌어옵니다. 페르소나는 기획용 가상 인물이며, 베타 전 사용자 인터뷰 5\~8명으로 확인하기를 권합니다.

## 5. 핵심 기능과 우선순위

**v5:** 1차(MVP)는 "주변 가게 탐색 → 가게 상세 → 길찾기 + 익명 제보" 입니다(팀 피드백 10-28). 취향 필터는 1차에도 있지만 **원할 때만 여는 선택 기능**이고, 확장은 2~3차에 피드백을 보고 합니다. 거지맵처럼 가입 없이 쓸 수 있어야 하고, 로그인은 도장·내 지도처럼 '내 기록'이 필요할 때만 요청합니다.

| 단계 | 기능 | 내용 | 로그인 |
| --- | --- | --- | --- |
| MVP | 떡볶이 지도 + 주변 가게 목록 (v5) | 접속 즉시 내 위치 주변 가게가 지도와 목록(거지맵식: 사진·이름·주소·거리·대표 가격·평점)에 바로 보임. 검색창(가게·동 이름). 핀 = 게이지 도장(8절) | 불필요 |
| MVP | 취향 필터 (v5: 선택 기능) | 필터 버튼 하나로 열림. 떡(밀/쌀/누들밀떡/가래떡), 스타일(국물/즉석/기름/로제/짜장/마라), 맵기 1\~5(신라면=3 기준표), 1인분 가격대, 영업 중. **결과 0곳이면 초기화 버튼**. 확장은 2~3차 | 불필요 |
| MVP | 가게 상세 | 정보 순서 = **이름 → 위치 → 떡볶이 종류 → 맵기 → 대표 가격 → 길찾기**(v5). 메뉴판, 맛 태그, 사진, 영업시간, 마지막 확인일과 ‘아직 있어요’ 버튼(가게 근처에서만), 길찾기(네이버·카카오 연결). 도장을 누르면 돌아가며 맵기 표정(v5, 상세에서만) | 불필요 |

| MVP | 지역·취향 목록 페이지 | '마포구 쌀떡볶이', '신당동 즉석떡볶이' 같은 검색 유입용 페이지 | 불필요 |

**평점 두 축(v5, 팀 결정 10-28):** v4까지는 별점을 빼기로 했지만, 맛은 주관적이라 리뷰가 있어야 한다는 팀 의견(✅)에 따라 **가게 별점(1\~5, 식당 자체)**과 **맛 평점(맵기 고추 1\~5)**을 따로 받습니다. 별점 조작·사장님 다툼을 줄이려고 ① 별점은 제보(방문)와 함께만 받고 ② 가게당 기기 기준 하루 1회 ③ 평점 개수가 3개 미만이면 숫자 대신 「아직 평가가 적어요」로 보여 줍니다. 노출 순서는 별점으로 정렬하지 않습니다(기본 가까운순·최근 확인순).

아래 메뉴는 네 칸입니다: **지도 · 목록 · 떡볶이방(2차) · 내 맛지도(2차)**. 제보 버튼은 지도 오른쪽 아래에 떠 있는 동그란 버튼으로 항상 보입니다.

## 7. 데이터 정책: 수집·검증·분류

서비스의 가치는 맛 태그의 정확도에서 나오므로, 태그는 정해진 보기에서만 고르고 자유 입력은 받지 않습니다.

**떡볶이 맛 태그 체계(v1)**

| 분류 | 보기 | 고르는 방식 |
| --- | --- | --- |
| 떡 | 밀떡, 쌀떡, 누들밀떡, 가래떡, 눈사람떡(작은 떡), 치즈떡, 분모자 | 여러 개 |
| 스타일 | 국물, 촉촉(일반), 즉석(냄비), 기름, 로제, 짜장, 마라, 궁중 | 하나 |
| 맵기 | 1 순한 \~ 5 아주 매움 (진라면 매운맛=2, 신라면=3, 불닭볶음면=4, 핵불닭 이상=5) + 가게의 단계 이름(예: 엽떡 초보맛) | 하나, 투표 평균 표시 |
| 맛 결 | 달콤, 짭짤, 단짠, 어묵 국물맛, 후추 맛 | 최대 2개 |
| 가격 | 1인분 기준 원 단위 + 확인일 | 숫자 |
| 같이 먹기 | 순대, 튀김, 어묵, 김밥, 라볶이 가능 | 여러 개 |
| 가게 유형 | 학교 앞, 시장, 포장마차, 프랜차이즈, 카페형 | 하나 |
| 이용 | 혼밥 가능, 포장, 배달, 주차, 현금만 | 여러 개 |

**처음 데이터 모으기(출시 전 300곳)**

1. 공공데이터포털의 일반음식점 인허가 데이터에서 업종·상호에 '분식·떡볶이'가 들어간 곳을 골라 후보 목록을 만든다(주소·영업 상태 포함).
2. 운영자와 초기 크루 10명이 직접 방문하거나 전화로 확인해 맛 태그를 채운다.
3. 네이버·카카오 리뷰나 사진을 통째로 가져오지 않는다(저작권·약관 위반). 사진은 직접 찍거나 제보자가 올린 것만 쓴다.

**등재 기준(3등급)**

- **떡볶이 전문:** 떡볶이가 대표 메뉴인 가게. 큰 핀.
- **분식집:** 떡볶이를 김밥·순대·튀김과 함께 파는 가게. 큰 핀.
- **메뉴에 있음:** 떡볶이가 메뉴에 있는 주점·카페·푸드코트. 작은 핀, 필터에서 끌 수 있음.

기준에 맞지 않는 가게는 사장님이 직접 올려도 내립니다(HappyCow 3등급, 거지맵 가격 상한에서 가져옴).

**제보 검증 규칙**

- 새 가게·폐업 제보: 운영자 승인 후 반영. 같은 내용 제보 3건이 모이면 우선 검토.
- 가격·맵기 변경: 제보 즉시 '확인 대기'로 표시, 다른 사용자 2명 동의 시 반영.
- 신선도: 마지막 확인일이 180일을 넘으면 핀을 흐리게, 365일을 넘으면 목록에서 내린다. 가게 근처에서 누른 ‘아직 있어요’가 마지막 확인일을 새로 고치고, 최근 확인된 가게를 목록 위에 둔다(가슴속 3천원·두쫀쿠맵 방식).
- 도배 방지: 익명 제보도 기기 및 IP 기준 하루 10건 제한. 사장님 비방·욕설은 필터 + 신고로 숨김.

맵기 기준표는 신라면=3으로 확정했습니다(2026-10-26). 베타에서는 이 기준표로 맵기 투표를 받으면서 2단계(진라면 매운맛)와 4단계(불닭볶음면) 기준 메뉴가 맞는지만 봅니다. 2020년 설문에서 ‘매우면서 달달’을 고른 사람이 70.6%여서, 단맛도 맵기처럼 단계로 따로 받을지 베타에서 함께 봅니다.

## 8. 브랜딩·디자인 방향

느낌은 '한지에 붓펜으로 눌러 쓴 편지'입니다. 떡볶이를 아끼는 사람들이 직접 써 내려간 지도라는 뜻을 미색 한지 바탕, 빨간 붓글씨 로고, 검은 손글씨 슬로건으로 보여 줍니다(2026-10-25 사용자 컨셉 이미지).

![떡볶여지도 컨셉 이미지: 한지 바탕, 빨간 붓글씨 로고, 계단식 세 줄 슬로건, 오른쪽 아래 서명](KakaoTalk_20261025_225207295.png)

- **슬로건:** "떡볶이를 사랑하는 사람에 의한, 떡볶이를 사랑하는 사람을 위한, 떡볶이를 사랑하는 사람들의 지도". 세 줄을 한 줄씩 오른쪽으로 밀어 계단처럼 놓는다. 세 구절이 서비스 뼈대와 맞물린다: 의한=익명 제보, 위한=취향 필터, 들의=함께 쌓는 지도.
- **색(v5.1, 11-01 · 슬랙 #design 10-28 반영):** 바탕은 한지 미색(#F3F0E9), 글은 먹색, **주 버튼·링크는 옥빛**(B 청자·N4 옥빛의 중간 #2A6159 · 링크 #2F6F70 — 팀 「빨간 버튼은 웹에서 경고색」), **고추장 레드는 포인트**로 로고·맵기 도장·제보 버튼 한 곳에만. 팔레트 이름 T(보드·웹 `?pal=T`). 팀장이 tweakcn 으로 만든 「떡볶이 초안 1」은 W 로 보관(비교용). (v5: 고추장 레드를 주 버튼까지 = R) 메뉴·가게 정보·버튼이 한눈에 구분되게 보조 버튼·태그는 먹색/회색. 배경·장식은 가독성을 위해 단순하게. 맵기 1\~5는 주황→검붉음 단계색 그대로. (v4: 한지 미색 #ECE1CF 바탕 + 붓 빨강 #C00000, 보드 규칙 「빨강은 로고·도장에만」 → 팀 피드백으로 바뀜)
- **로고:** 빨간 붓글씨 '떡볶여지도'. 첫 화면 왼쪽 위에 크게 두고, 첫 화면·공유 카드 끝 오른쪽 아래에 작은 서명으로 한 번 더 찍는다(편지 끝 서명처럼). **(11-01 팀 제안)** 첫 화면 오른쪽 아래 서명 자리에 확정된 캐릭터를 넣거나, 로딩(스플래시) 때 캐릭터를 잠깐 보여 주고 지금 화면으로 넘어가기 — 캐릭터가 정해진 뒤 2차에.
- **지도 핀(v5):** 네모 인장 모양은 유지하되 **숫자는 쓰지 않는다.** 도장 안이 맵기 단계만큼(1~5) 아래에서 위로 차오르는 게이지(당근 매너온도처럼)이고, 찬 부분 색은 1 주황 → 5 검붉음, 도장 바로 아래 작은 알약에 고추 n개. 캐릭터·표정은 핀에 넣지 않는다(팀장). 상세 화면에서만 도장을 누르면 돌아가며 표정이 나온다. #design 10-28: 네모 캐릭터 핀은 지도에서 너무 커서 캐릭터로 안 보이고, 확대하면 실제 지도로 넘어가니 **확대 전 크기 기준**으로 핀을 생각한다 → 핀은 도장, 캐릭터는 1 도장이·2 떡순이 두 방향을 따로 발전(2차). (v4: 도장 속 숫자가 맵기) 떡볶이 전문·분식집은 큰 도장, ‘메뉴에 있음’은 작은 도장. 마지막 확인일이 180일을 넘으면 대동여지도 여백의 바랜 도장처럼 흐리게 찍는다. 가게가 몰린 곳은 둥근 도장에 가게 수를 쓴다. (v3까지는 떡볶이 그릇 모양 핀)
- **지도 바탕:** 대동여지도(김정호, 1861) 느낌으로 그린다(2026-10-26 사용자 참고 이미지, 폴더의 참고_대동여지도.jpg). 한지 바탕에 산줄기·물줄기는 옅은 먹선, 강과 물가는 쪽빛 선, 큰길은 곧은 먹선에 일정 간격의 점(대동여지도의 10리 표시)을 찍는다. 첩을 이어 붙인 이음선은 옅은 격자로 남기고, 지명은 목판 인쇄 느낌의 명조 글꼴로 쓴다. 이름의 ‘여지도’가 대동여지도와 겹쳐서, 지도 모양이 곧 이름을 설명한다.
- **글꼴:** 로고·슬로건·제목만 손글씨, 본문·가게 정보·지도 글자는 Pretendard. 손글씨는 짧은 글에만 써서 읽기 쉽게 한다.
- **바탕 질감:** 첫 화면·목록·공유 카드에 한지 질감을 깔고, 지도도 한지 바탕으로 그린다. 대신 지도 위 산줄기 결은 옅게 깔고 길·지명·도장은 진하게 올려 글자와 핀이 묻히지 않게 한다. (v3까지는 지도 위에는 질감을 깔지 않기로 했음)
- **말투:** "오늘은 어떤 떡?", "여기 국물 진해요", 제보 완료 시 "서비스 어묵 하나 올려 드렸어요". 포인트를 두면 이름은 '어묵'.
- **도메인:** 떡볶여지도.com(한글) + 기억하기 쉬운 영문(예: tteokmap 계열) 동시 확보. 한글 도메인은 공유 시 주소가 깨져 보일 때가 있어 영문 주소를 기본 공유 링크로 쓴다.
- **화면 원칙:** 휴대폰 세로 화면이 기본. 지도가 화면의 70%, 아래에서 올라오는 가게 카드.

도메인 사용 가능 여부와 상표(떡볶여지도) 출원 여부는 아직 확인하지 않았습니다. 컨셉 이미지의 빨간 물결 밑줄은 편집 화면 표시로 보고 뺐고, 점선 격자는 대동여지도의 첩 이음선과 닮아 지도 바탕의 옅은 격자로 살렸습니다(2026-10-26). 이미지 속 손글씨가 직접 쓴 것인지 글꼴인지, 글꼴이면 상업용으로 써도 되는지 확인이 필요합니다.

## 9. 기술 구조와 비용

출시 단계는 앱 없이 모바일 웹 하나로 갑니다. 거지맵도 웹으로 시작해 "앱 설치 없이 쓴다"는 점이 입소문의 이유가 되었고, 혼자 만들기에도 가장 빠릅니다.

| 영역 | 선택 | 이유 | 월 비용(초기) |
| --- | --- | --- | --- |
| 화면 | Next.js (모바일 웹 + 홈 화면 추가 가능한 PWA) | 지역·취향 목록 페이지를 검색에 노출하기 좋음 | 0원 |
| 배포 | Vercel | 사용자가 이미 쓰는 곳(saret-system) | 0원 → 트래픽 늘면 약 2만 원 |
| 지도 | 카카오맵 JavaScript API (+ 길찾기는 네이버·카카오 앱 링크) | 국내 주소 정확도, 무료 제공량 있음 | 무료 범위 안 |
| 데이터·로그인 | Supabase (Postgres + PostGIS 거리 검색, 카카오 로그인) | 가까운 가게 검색과 익명 제보를 한 곳에서 | 0원 → 약 3만 원 |
| 사진 | Supabase Storage 또는 Cloudflare R2, 올릴 때 자동 축소 | 사진이 가장 큰 비용 요인 | 수줜 원 |
| 운영 도구 | 제보 승인용 관리자 화면(자체 제작, **v5: 추후 확장** — 1차는 운영자가 DB에서 직접) | 제보 하루 수십 건을 버튼 한 번으로 승인 | 0원 |
| 분석 | GA4 + Vercel Analytics | 검색 유입·필터 사용 측정 | 0원 |

초기 월 비용은 도메인을 빼면 0원에서 시작해, 월 이용자 3만 명 수준에서도 약 5만 원 안쪽으로 보입니다(추정치). 카카오맵은 2026년 7월 21일 이후 활성화한 앱에 새 무료 제공량 정책이 적용되므로, 개발 전에 [카카오 개발자 센터](https://developers.kakao.com/docs/latest/ko/kakaomap/common)에서 현재 한도를 확인해야 합니다([공지](https://devtalk.kakao.com/t/api-notice-on-new-kakao-map-api-features-and-free-quota-policy/150222)). 앱스토어 앱은 월 이용자 1만 명을 넘긴 뒤 검토합니다.

지도 바탕을 대동여지도처럼 꾸미려면 바탕 지도의 색과 선을 직접 바꿀 수 있어야 합니다. 네이버 클라우드 Maps는 네이버 지도 커스텀 스타일 기능을 안내하고 있고([Maps 개요](https://guide.ncloud-docs.com/docs/ko/maps-overview)), 카카오맵 JavaScript API에서는 같은 기능을 찾지 못했습니다(공식 문서로 다시 확인 필요). 개발 전에 셋 중 하나를 고릅니다: ① 네이버 지도 커스텀 스타일, ② 오픈 지도 데이터(OpenStreetMap) + MapLibre로 바탕을 직접 그리기, ③ 카카오맵은 그대로 두고 한지 테두리와 도장 핀만 얹기.

## 10. 수익 모델

처음 6개월은 수익보다 신뢰가 우선입니다. 거지맵도 "광고가 거의 없다"는 점이 장점으로 꼽혔고, 맛집 지도는 "돈 받고 올린 가게"라는 의심이 생기는 순간 무너집니다. 그래서 가게 노출 순서는 절대 팔지 않고, 표시된 광고만 받습니다.

| 시점 | 수익원 | 방식 | 주의 |
| --- | --- | --- | --- |
| 출시 직후 | 없음 | 데이터와 사용자 모으기에 집중 | - |

| 월 1만 명\~ | 표시된 광고 칸 | 목록 중간 1칸, 분식 브랜드·소스 회사 | "광고" 표시, 지도 핀에는 없음 |

노출 순서와 태그는 어떤 수익원과도 바꾸지 않고, 화면을 가리는 전면 광고는 쓰지 않습니다. 거지맵은 출시 때 ‘업장에서 돈 안 받음’이라 했다가 지금은 앱테크 포인트·쇼핑 적립·광고로 옮겼고, 앱 리뷰에 전면 광고 불만이 올라와 있습니다.

## 11. 성장·운영 전략

거지맵은 광고 없이 당근 입소문으로 커졌습니다. 떡볶여지도도 "동네 노포를 아는 사람이 자랑하고 싶게" 만드는 것이 성장 전략의 전부입니다.

**입소문 통로**

1. **동네 커뮤니티:** 당근 동네생활, 대학 에브리타임에 "우리 동네 떡볶이 지도 완성 중, 빠진 곳 제보해 주세요" 글.
2. **공유 카드:** "나의 떡볶이 취향 검사(쌀떡·국물·맵기 4)" 결과를 인스타 스토리 이미지로. 결과에 맞는 가까운 가게 3곳 추천.
3. **검색 유입:** 구·동 × 취향 조합 목록 페이지(예: /seoul/mapo/rice-cake). 가게가 늘수록 페이지가 자동으로 늘어남.
4. **덕후 크루:** 떡볶이 기록 계정 운영자에게 '떡마스터' 배지와 자기 지도 페이지를 주고 초기 데이터 제보를 부탁.
5. **월간 이벤트:** "이달의 떡볶이 월드컵"(구별 투표). 결과는 가게에 인증 스티커로 전달해 오프라인 노출.
6. **연례 발표·현장:** 매년 한 번 ‘지역 떡볶이 100곳’ 발표(타베로그 햐쿠메이텐 방식). 10월 대구 북구 떡볶이 페스티벌(2025년 33만 명 이상)에서 현장 지도 배포.

**지역 순서:** 마포·서대문(대학가) → 중구 신당동(즉석떡볶이 골목) → 서울 전역 → 수도권 → 부산·대구 등 광역시. 한 지역을 최소 100곳 채운 뒤 다음 지역을 연다. 핀이 드문 지도는 첫인상에서 실패하기 때문입니다.

**운영 루틴(1인 운영 기준)**

- 매일 20분: 제보 승인·신고 처리
- 매주: 확인일 180일 지난 가게 목록 점검, 인스타 콘텐츠 2개
- 매월: 월드컵 진행, 지표 점검

기존 인스타 자동화 프로젝트의 예약 게시 흐름을 떡볶이 콘텐츠에 재사용하면 주간 콘텐츠 부담이 줄어듭니다.

## 12. 성공 지표와 로드맵

기준 지표는 '필터를 쓴 뒤 길찾기까지 간 방문'입니다. 취향으로 찾아 실제로 가게에 간다는 떡볶여지도의 존재 이유를 가장 직접 보여 주기 때문입니다.

**v5 일정 메모:** 팀장 피드백은 「다음 주 완성」을 전제로 합니다. 1차 UI/UX 판을 **11월 첫째 주(11/2~11/8)**에 배포해 팀이 써 보고, 피드백을 받은 뒤 데이터(300곳)·제보 저장(Supabase)·공개 출시 순서로 갑니다. 출시 로드맵 보드의 M1~M5·공개 출시(2027-01-11 주) 주차는 이 순서에 맞춰 다시 짜야 합니다(사용자 결정, 보드 D-13).
