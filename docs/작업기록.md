### ⏸ 2026-11-08 — 웹 2차 (브랜치 web_2): 떡볶이방 · 맛집 리스트 · 흰 바탕 · 고추 핀 · 화면 스튜디오

**사용자 요청 순서:** 개발자 main·슬랙 정리 → 메뉴 셋(지도 · 떡볶이방 · 내 맛지도) → 떡볶이방 = 게시판, 내 맛지도 = 장소 리스트 만들고 공유·추천 → 글 추천 → PC 목록 칸 흰색 + 보드에 모바일·PC 화면 스튜디오 → 바탕 전부 흰색 → 등록 화면 간격 → 지도 핀 「고추 개수」 → 상세 머리칸 사진 시안(→ 도장 자리로 되돌림) → 「web_2 로 병합」.

**웹 (web/)**
- 127.0.0.1 로 열면 React 가 안 붙어 지도가 안 뜨던 문제: `next.config.ts` `allowedDevOrigins: ["127.0.0.1"]`.
- 메뉴 셋: 지도 · 떡볶이방(`/room`) · 내 맛지도(`/mine`). 「목록」은 메뉴에서만 뺌(`/list` 남김). 「함께 고치기」 페이지는 지우고 가게 상세 맨 아래 「함께 고치기」 칸(빠진 정보 + 고치기 넷)으로. `/together` → `/`.
- 떡볶이방 게시판: 말머리 셋(자유·맛집 추천·같이 가요) · 글쓰기(가게 붙이기 선택) · 댓글 · 추천(엄지척) · 내 글 지우기 · 신고 3명이면 가림. API `/api/room`.
- 내 맛지도: 탭 넷(내 리스트 · 모두의 리스트 · 찜한 가게 · 내 등록). 리스트 = 이름·설명·공개 범위(모두에게 / 링크로만) + 가게 순서. 주소 `/lists/[id]`, 지도에 도장 + 번호 줄, 만든 기기만 고침, 추천은 기기당 한 번(내 리스트는 못 함). 가게 상세 「＋ 내 리스트에 담기」. ♡ 는 「찜」으로 이름 바꿈. API `/api/lists` · `/api/lists/[id]` · `/api/me`(이 기기 것).
- 저장은 여전히 `web/.data/db.json` 임시 파일. 예전 db.json 을 읽으면 게시판·리스트 예시를 채운다. **Supabase 전에는 Vercel 에서 글·리스트가 저장 안 됨.** 「내 것」은 로그인 없이 기기 표시로만 가른다.
- 색: 팔레트 **T2 흰 바탕**을 기본으로(바로 전 기본은 `?pal=T`). 지도 그림 바탕만 한지 미색(`mapPaper`). PC 왼쪽 가게 줄 칸 = `--panel`.
- 등록 화면(1280 이상): 제목·단계 목록을 화면 왼쪽 끝으로. 입력·지도 칸 자리는 그대로.
- 지도 핀: 「게이지 도장」 → **「고추 개수」 알약**(테두리 = 맵기 색, 고른 가게는 옥빛 바깥 테두리). 카드·상세·필터의 HTML 도장은 아직 예전 모양.
